# Security basics

## Accounts

Use Vaultwarden, the company password manager, for every work password. Multi-factor authentication is mandatory on email, GitHub and the cloud console; hardware keys are provided on request.

## Devices

Laptops must use full-disk encryption and lock after 5 minutes of inactivity. Never leave a laptop unattended in a vehicle.

## Reporting

Report phishing or a lost device in the #sec-alerts channel immediately. For an urgent security incident outside office hours, call the security hotline at extension 4400.
